## Tujuan Repositori
Repository ini berisi penyelesaian tugas dan praktik Matematika Diskrit. Berisi implementasi program Python untuk memodelkan relasi/fungsi, konversi antar basis bilangan secara algoritmik (biner, oktal, hexadecimal), pengecekan bilangan prima, kalkulasi FPB & KPK, serta analisis sekumpulan data bilangan.

Repositori ini dibuat untuk memenuhi tugas praktikum mata kuliah **Matematika Diskrit (Modul 2)**. Tujuan utama dari pembuatan repositori ini adalah:

1. **Menjembatani Teori dan Komputasi:** Mengimplementasikan konsep matematika abstrak (relasi, fungsi, sistem bilangan, dan teori bilangan) ke dalam kode program terstruktur berbasis **Python**.
2. **Pemodelan Algoritma:** Melatih kemampuan berpikir algoritmik mulai dari pemahaman masalah, penyusunan *pseudocode* dan *flowchart*, hingga implementasi program modular.
3. **Analisis Komputasional & Efisiensi:** Menerapkan algoritma konversi basis bilangan secara manual.serta menguji efisiensi komputasi (seperti optimasi pengecekan bilangan prima berbasis dan Algoritma Euclidean untuk FPB. 
4. **Dokumentasi & Portofolio:** Menyimpan hasil asesmen integratif (*Problem Challenge*) dan mendokumentasikan pengujian kode program standar maupun *edge cases*.
